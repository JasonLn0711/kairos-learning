# 參考架構

## Context

收件人員透過本機瀏覽器操作教學檢核系統，輸入合成字串並下載 JSON；沒有外部業務系統、模型 API 或正式業務規則服務。Coding Agent 是開發工具，不是運行時的審核者。

## Container

瀏覽器 → 本機 Streamlit 程序：輸入欄位與操作事件。Streamlit 程序呼叫同一程序內的 rules.py：純函式驗證與匯出。程序 → 瀏覽器下載：經驗證、只含允許欄位的 JSON。

使用 Streamlit 預設前後端通訊；本課不將它描述成自行設計的 REST API。rules.py 是程序內元件，不是獨立 Container。無持久資料庫；輸入與 checked 快照留在工作階段記憶體，下載檔留在操作者管理的檔案系統。

## 信任邊界與限制

輸入跨越瀏覽器與 Python 程序邊界，不能只信任 UI 的 max_chars；純函式仍檢查型別與長度。JSON 匯出只採三個允許欄位，呼叫時重新驗證。程序監聽 127.0.0.1 供本機教學，不假定此設定能建立正式多人隔離。

本原型沒有 Authentication、Authorization 或正式 Session 治理。多人版需另定身分來源、每次資料存取的授權、儲存、加密、備份與維運；目前不得用本機測試推定這些需求已完成。
