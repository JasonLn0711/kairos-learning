# 案例 2 小任務：用 10×10 方格算面積

教材 1.8 · 2026-10-22 · 建議預留 5–10 分鐘

小島創作所要估算紙面色塊的面積。先把紙看成方格紙，每格是一個像素，數出塗色格子，再換成平方毫米。

## 觀察

 如圖 2-1，10×10 共有 100 格，其中第 3–6 列、第 4–8 欄塗色，共 4×5＝20 格。每格邊長若是 2 mm，一格面積就是 4 mm²。      圖 2-1．面積教學示意圖。塗色區域有 20 格；每格邊長 2 mm，因此面積為 20×2²＝80 mm²。先數整個區域，再換算單位；對應下方短例子與完整流程第 6 步。  

## 操作

在 MATLAB Command Window 貼上以下程式，或開啟 case2_quickstart.m 按 Run。輸出顯示在 Command Window，變數留在 Workspace。

```matlab
mask = false(10,10);
mask(3:6,4:8) = true;
pixelSizeMm = 2;
areaSquareMm = nnz(mask) * pixelSizeMm^2;
disp([nnz(mask) areaSquareMm]);
```

## 預期結果與解釋

預期顯示  20 80 ，分別是選中像素數與平方毫米面積。 false(10,10)  建立全為假的方格， true  標記選中的格子；這張真假表就是遮罩。 nnz  數出真值，邊長平方再把像素數換成面積。

## 理解檢查

同樣 20 格，邊長改成 1 mm，面積是多少？

答案：20 mm²。邊長由 2 mm 減半，每格面積變成四分之一，所以總面積由 80 變成 20 mm²。
