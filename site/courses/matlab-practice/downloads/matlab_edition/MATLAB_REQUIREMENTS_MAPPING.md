# 三題需求與合成教材對照

這份對照表把已核對的老師要求、助教實作方式與合成案例範圍分開記錄。三個案例用於課前練習，資料內容維持虛構，作業內容請依老師提供的正式題目完成。

## 案例一：表格分類

| 項目 | 已核對的老師要求 | 合成教材做法 |
| --- | --- | --- |
| 資料切分 | 80% Train Set、20% Test Set | 虛構設備感測資料依標籤分層切成 80/20 |
| 成績解讀 | 90% 為目標值 | 教材照實呈現 accuracy、混淆矩陣與正類召回率 |
| PDF 內容 | 分析邏輯、特徵選取、程式碼截圖、測試結果 | `CASE1_REPORT_TEMPLATE.md` 與 PDF 範本依四節排列 |
| 程式與附加檔案 | PDF 四節屬老師要求 | 獨立 `.m`、CSV、JSON、檢核程式與教材 ZIP 屬助教實作方式 |

合成案例使用 `temperatureC`、`vibrationMmS`、`currentA` 預測正常或需檢查，避開正式題目資料。模型選擇與安全路徑檢核屬助教為初學者設計的實作方式。

## 案例二：影像分割與面積

| 項目 | 已核對的老師要求 | 合成教材做法 |
| --- | --- | --- |
| 輪廓顏色 | 紅色外輪廓 | 疊圖使用 RGB `[255 0 0]` |
| 比例 | 每個像素為 1 mm × 1 mm | `pixelSizeMm = 1.0`，面積平方毫米等於原始元件像素數 |
| 面積來源 | 量測目標區域 | 從原始分割元件計算 `pixelArea`，輪廓像素另列 |
| PDF 內容 | 執行結果、處理程序、程式碼 | `CASE2_REPORT_TEMPLATE.md` 與 PDF 範本依三節排列 |
| 程式與附加檔案 | PDF 三節屬老師要求 | 獨立 `.m`、PNG、JSON、檢核程式與教材 ZIP 屬助教實作方式 |

合成案例使用紙面不規則柔和紅色色塊與藍色干擾塊，避開正式題目的影像內容。

## 案例三：圖庫分類

已核對的資料範圍共有三組 ZIP，合計 234 張影像：

- 魚類：Train 46、Test 10。
- 馬與驢：Train 80、Test 20。
- 場地：Train 64、Test 14。

水果壓縮檔與老師另外提供的題目圖片位於目前已核對範圍之外。教材因此維持圓形、三角形、方形的合成圖庫，模擬「既有 Train Set／Test Set 資料夾、讀圖、抽特徵、訓練、獨立測試」流程，並保留目前 108 張 Train、45 張 Test 的教材規模。

已核對的報告內容為「執行結果、處理程序、程式碼」。`CASE3_REPORT_TEMPLATE.md` 依這三節排列。PDF 格式、獨立 `.m`、manifest、PNG、JSON、檢核程式與教材 ZIP 均標示為助教實作方式。案例三目前未設定特定正確率門檻，也不把 80/20 套用到既有 Train/Test 資料夾。

## 閱讀與執行原則

- 三份逐段教材以最終 `.m` 的實際行號與 SHA-256 為準；每段保留完整程式片段，段內涵蓋每個非空行。
- GPT／Claude 負責產生或解釋文字；MATLAB Desktop／Online 的真實輸出才是執行依據。
- MATLAB 執行結果、截圖與報告數值由同學在自己的授權環境產生並保存。
- 教材的報告 PDF 是可編輯內容範本；案例一依要求填入程式碼截圖，案例二、三則填入程式碼，採截圖呈現時請保持文字清楚。
