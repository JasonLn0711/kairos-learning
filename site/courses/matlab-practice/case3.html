案例三逐段教學：合成幾何圖形分類

先看全程｜從 Train／Test 圖庫到圖片分類報告

這個案例要完成什麼？

我們用圓形、三角形與正方形的合成圖片，做出一套能讀圖、取特徵、分類，再核對測試答案的流程。先用 Train Set 建立判斷方式，再對 Test Set 逐張預測，最後整理結果、處理程序與程式碼。

本案例是「助教實作方式」。第三題已收到的圖庫按 Train Set／Test Set 分開；Jason 的課務回覆確認成果包含「執行結果、處理程序、程式碼」。本教材採 PDF 與 .m 整理成果，屬助教實作方式。正式作業要處理的資料組數、指定格式及其他規則，依完整題目與後續公告確認。

從頭到尾，依序做這 8 件事

  1. 先開啟程式，認識資料夾。 進入 matlab_edition，開啟 case3_shape_classifier_matlab.m，跟著後面的段落與四階段提示詞練習。完整參考版輸入 s = case3_shape_classifier_matlab;，結果存到 matlab_artifacts/case3。重跑會更新同名範例輸出。
  2. 先盤點圖片與答案，再開始分類。 本例建立 108 張 Train 圖與 45 張 Test 圖，放在 images/train 與 images/test；train_manifest.csv、test_manifest.csv 記錄圖片相對路徑與正確標籤。抽開幾張圖，確認清冊中的路徑真的找得到圖片、標籤對得上內容。正式圖庫則先沿用已提供的 Train／Test 分組。
  3. 確認練習圖片與測試圖片分開。 程式檢查完整路徑與解碼後像素的交集，結果寫入 evaluation.json。本例實測跨組交集皆為 0。這項檢查針對完全相同的圖片；正式資料也要留意近似圖片、同一物件與同一拍攝來源，依資料特性安排檢查。
  4. 把圖片變成模型看得懂的數字。 本例讀取前景，為每張圖算三個特徵：填滿程度 fillRatio、接近圓形的程度 circularity、前景占整張圖的比例 areaRatio。先看幾張圖，再對照特徵，說明這些數字為什麼可能分得出三種形狀。換成正式照片時，要重新評估特徵與前景處理方式。
  5. 只用 Train 建立判斷方式。 先用 Train 特徵算平均值與標準差，再套用到兩組資料。本例採三近鄰：對一張待分類圖片，找出特徵最接近的三張 Train 圖，由它們的標籤投票。清楚區分「建立參考資料」與「對 Test 預測」，把方法與參數寫進處理程序。
  6. 逐張預測 Test，再對照正確答案。 開啟 test_predictions.csv 看每張圖的真實標籤與預測；查看 evaluation.json 的類別順序、混淆矩陣及正確率。本例實測答對 44／45 張，約 97.78%。把判錯的圖片找出來，觀察形狀或特徵可能造成的混淆。自己的報告記錄自己的實際結果。
  7. 整理讀者能核對的結果。 保存兩份清冊、逐張預測、評估摘要、程式與代表性圖片。說明圖庫張數、前處理、特徵、分類方法、測試方式與錯誤案例。可執行 run_matlab_tests 檢查教材參考版；真實照片的辨識表現與資料特性另行評估。
  8. 把成果整理成三部分，再對照正式題目。 依 CASE3_REPORT_TEMPLATE.md 整理「執行結果、處理程序、程式碼」。本教材示範匯出 PDF 並保留 .m；繳交格式、要完成的圖庫範圍與管道，最後再按正式說明確認。若需處理多組圖庫，每組各自留下資料設定、測試結果與錯誤分析，讓報告能清楚對應。

做完時，你手上應該有什麼？

  • 練習過程：一支 .m、Train／Test 圖庫、兩份清冊、test_predictions.csv 與 evaluation.json。
  • 報告證據：資料分組、圖片特徵、模型方法、逐張預測、混淆矩陣與錯誤案例。
  • 成果整理：依課務已說明的三項內容撰寫報告；PDF 與 .m 是本教材採用的助教實作方式，正式交件細節依完整題目確認。
