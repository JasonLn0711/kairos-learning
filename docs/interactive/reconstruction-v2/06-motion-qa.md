# Task 06　動態與狀態驗證

![上排參考步驟取樣，下排本站實際 HTTP 請求](../../../.local/interactive-v2/task06/storyboard.jpg)

Playwright 人工時鐘控制實際頁面的重播。執行 node tests/visual-gallery/motion.mjs，1440×900 的第 5 步在 0、325、660 ms 的 SVG 中心分別為 (132,195.5)、(175.82,195.5)、(221,195.5)。650 ms 旅行結束後停在接收端。參考為複寫場景的連續取樣，對照的是訊息沿已知邊移動的方式；本站用封套與回應變體辨識方向。[時間與座標](../../../.local/interactive-v2/task06/clock.json)

| 案例 | 驗證方式 |
|---|---|
| 暫停、續播、seek、重播 | 純函式 0／50／100% 與跳時測試；實際頁面以 Space 暫停與恢復 |
| DNS 快取、DB 慢查詢 | 切換情境後檢查無跨機路徑、停等位置、返向接收端 |
| 數學 | 預設 1、0 得 3.076；同分得 4；畫面保留未四捨五入數值供計算 |
| 政策 | 逐關比對執行、驗收與 skipped；結果限定本機合成輸入 |
| 可達性 | 減少動態使用靜態路徑及文字，讀者可用原生控件開關解說，狀態列不逐幀更新 |

完整互動、歷史導覽、雙語、數學與權限案例的 Playwright 實測結果彙整於 Task 07 紀錄。
