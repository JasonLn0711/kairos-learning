# Task 08　首批三課驗收

**Gate A 工程檢查通過，整頁視覺評分待核。** Request Lifecycle 保留十步、兩種語系、DNS 快取與慢速資料庫。使用者已確認人物、伺服器與封包「三者都能辨認」。這項回饋對應圖形辨識。整頁的構圖、動態及閱讀順序另列如下。

| 人工評分項目 | 權重 | 工程觀察與複核位置 |
|---|---:|---|
| 構圖與視窗 | 25 | 1280×720 中央內容寬由 688 增至 733 px，操作列底緣 708 px。請比較首步的取景與第五步的完整拓樸。 |
| 輪廓、投影與深度 | 20 | 三個代表圖形已獲辨識確認。請再比較整圖線寬、陰影與物件比例。 |
| 狀態與動態 | 20 | DNS cache 改變路徑，慢速 DB 改變等待。本機處理以進度線呈現；分鏡可比較移動起點、中段及終點。 |

| 層次與易讀性 | 10 | 起始鏡頭聚焦人物及瀏覽器。檢查第二步 DNS 出現後，是否容易從說明找到對應物件。 |
| 響應與無障礙 | 10 | 桌面單視窗、手機縱向閱讀，鍵盤、放大文字、減少動態與無 JS 另有自動驗證。真機操作待驗。 |

**Gate B 工程檢查通過，整頁人工驗收待核。** Softmax 直接使用教材的權重與加權結果，單元測試比對 1,089 組輸入。Four Gates 測試涵蓋 16 組布林輸入與關卡跳過狀態。未發現阻斷三課使用的 P0。P1 待驗項目為整頁人工評分與其他瀏覽器。P2 為真機字體及窄版捲動手感。目前不填代評分數。
