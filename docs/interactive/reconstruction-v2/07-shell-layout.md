# 桌面工作區與窄版閱讀

沿用 ImmersiveShell、InteractiveFrame 與語系路由。桌面最大內容寬度由 1600 擴到 1920 px，課程列與解說列各有上下界，中央舞臺取得剩餘寬度。保留 100dvh 與 minmax(0,1fr) 的垂直空間分配，步驟控制留在舞臺下方。右側解說保留命名與 Tab 焦點，長文可使用鍵盤捲動。窄版解除右列分隔，改上下閱讀，支援 safe-area 底部間距；控制最小高度 44 px。完整解說與來源透過同一個原生 dialog 開啟。靜態 HTML 保留全文、考題與源節連結。

參考頁使用中央時間線，本站左列仍是可定位的課程步驟或章內概念。這個選擇保留原本課程導覽與第 1 步的筆電焦點。1920 寬使用額外空間呈現較大的場景，窄版允許頁面自然捲動。樣式限定於互動課頁元件。
