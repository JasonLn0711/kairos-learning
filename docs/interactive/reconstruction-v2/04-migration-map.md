# 角色接入位置

基準與分支沿用 Task 02。registry.ts 對應原始五個 node kinds；新 RoleGlyph 的人形附在筆電旁，路由與網路邊只引用原本五種節點。每個實例由頁面或 fixture 提供可讀標籤；圖案的內部警示或成功徽章不加入 Tab 順序。

| 原位置 | 接入方式 | 保留條件 |
|---|---|---|
| InteractiveStage 的 entity | 替換共用機箱造型為 role 對應元件 | 保留 data-node、focused、雙語名稱與原始路徑方向 |
| 原 packet halo | marker 中心放入 request、response、data 或 secure | 停等位置與教學狀態同步 |
| ground 與 idle-link | 與新基元共享繪序、色面及接點 | 課程來源不得新增未授權路徑 |
| LearningStage、PolicyStage | 接入資料與狀態介面 | 使用數學及政策呈現，不呼叫設備 registry |

Task 04 僅新增圖件、registry、隔離圖集與本機證據。產品頁於後續轉接階段接入。
