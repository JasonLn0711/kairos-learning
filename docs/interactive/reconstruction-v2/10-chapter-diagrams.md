# AASE M02 章節流程圖

M02-01 至 M02-06 各有一張中英文可切換的章節 SVG。原課頁的「在本頁閱讀章節流程圖」展開同一個閱讀器。互動學習首頁直接列六章。既有概念網址保留相容入口，例如 `m02-01/embeddings/?step=2` 會移到章內的 `#embeddings-02`。

| 章節 | 概念／分鏡 | 讀圖時追蹤的變化 |
| --- | --- | --- |
| M02-01 | 8／24 | 從詞元、ID、矩陣列、位置與注意力，一路追到下一個詞元。交換兩個名字會交叉兩條位置線。 |
| M02-02 | 6／18 | 區分已儲存與已送入的資料，用相同容量刻度比較新增日誌前後的預算。 |
| M02-03 | 6／18 | 依問題選擇快取、摘要、擷取或記憶。讀取文件時追蹤版本與條款，另核對實際行為。 |
| M02-04 | 6／18 | 固定規則與受限探索各有決策路徑。操作範圍、審查、時間或預算會改變授權結果。 |
| M02-05 | 6／18 | 六種支援職責以點線連到模型。工具可被發現後，宿主仍須判斷這次呼叫是否有權執行。 |
| M02-06 | 8／24 | 從提案、呼叫識別碼與政策，追到執行、回應和驗收。授權失敗後，執行與驗收兩關會標示略過。 |

章節關係定義在 [plans.ts](../../../src/lib/interactive/chapter/plans.ts)。每幕使用[原教材](../../../content/interactive/aase-m02/)的資料與來源錨點，依[分鏡](../../../src/lib/interactive/visual/aase/storyboards.ts)組合物件。閱讀器切換 SVG 的取景範圍，保留同一張圖。圖中能比較數值的案例包含矩陣查列、共同分母與加權和、容量上限及條件變動後的停止位置。切詞到嵌入的編排參考 Raschka 以同一筆資料展示連續轉換的方式。[參考教材](https://github.com/rasbt/LLMs-from-scratch/blob/main/ch02/01_main-chapter-code/ch02.ipynb)

## 規則與驗證

| 適用規則 | 本機驗證 |
