# M09-04｜圖形推理參考解答

> 網站預設收合。此為示範解說，閱讀參考答案不等於完成理解檢核。

## 1. 哪道界線不能沿用員工的授權？

訪客從公共區跨入管制區的那條路，不能因員工刷卡成功就自動成立。員工的憑證與存取權屬於員工；門打開只是設備狀態，沒有證明訪客身分、工作安排及可進入範圍都已核實。訪客也可能已有合法安排，所以要查訪客程序，而不是只憑外觀定罪。

## 2. 三個概念與目前證據

「臨時維修、先進去再說」若是捏造的合理化故事，可能是 Pretexting（情境編造）；用免費工具誘導使用未知裝置，可能是 Baiting（誘餌）；未經必要授權跟隨進門，可能是 Tailgating（尾隨進入）。這些分類可以同時成立。但目前缺少工作與訪客核准等紀錄，只能辨認風險與待查問題，不能逕稱全部惡意、程式已執行或資料已外洩。

## 3. 先處置什麼，補什麼證據？

先不使用未知隨身碟、不提供額外資料或存取，依程序聯絡既有接待／承辦／保全或資訊窗口，核對工作安排、訪客身分與範圍。人身安全優先，不自行攔阻或追逐。保存已有時間、地點與當事人陳述；若有權且必要，再交叉查訪客登記、門禁及相關影像、裝置連接與執行紀錄。這些紀錄可能不存在或不完整，應標示未知，不把缺紀錄當成沒發生，也不擅自製造新的危險測試。

**推理重點：先辨認跨越的邊界，提出能驗證該邊界的證據，再依已知風險處置。不是多猜幾個攻擊名詞就比較正確。**
