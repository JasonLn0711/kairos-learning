# M02-02 參考解答

## answer-roots｜1. 三個網址不等於三個獨立來源

不能。三者都追到同一篇論壇文，只有一條共同上游。應尋找取得途徑不同、時間與對象一致的原始紀錄，並核對它是否真的支持同一主張；不是單純再找第四個轉貼網站。

## answer-time｜2. 文件日期與環境不能混在一起

不能。今天下載不會把去年的內容變成現況；徵才技能不等於正式部署，測試環境也不等於正式環境。即使確認使用 X，還需要版本、配置與弱點適用條件的另行授權驗證，才能討論實際弱點。

## answer-hash｜3. 雜湊支持內容比對，不替故事背書

若比較基準可靠，相同雜湊可高度支持保存內容未變，但不能保證截圖原本就是真的、由誰建立、何時拍攝或是否截掉重要上下文。也不是數學上絕不碰撞的保證。造假檔案也能算出正確雜湊。

## answer-missing｜4. 搜尋的空白不是資產不存在的證明

不能直接刪除。應記為「在本次指定來源、查詢與時間範圍內未找到」，保留涵蓋範圍的限制，再由獲授權的現行資產紀錄或負責人核對。不要為補足缺口自行掃描超出授權的目標。
