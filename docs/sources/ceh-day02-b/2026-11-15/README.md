## 編輯調整與技術邊界

- 移除重複favicon卡與檔名，原件不變；改列可追查的一手來源。
- 供稿提到另份附件／原題庫，但本次只有一份教學稿與五PNG。保留23題對照與三題待核，不補造題幹、選項、題庫答案或原smtp命令。
- 原「提交作答並進行批改」改成六題靜態自我檢核；無提交、批改、持久化或學習完成服務。閉卷23題需要另持原題庫。
- 銀行情境原表格第一列看似表頭，改成「觀察項目／測試紀錄（假設資料）」並將ICMP Echo列放回資料列，七項觀察全部保留。
- ICMP Type 3 Code 3明示ICMPv4；UDP靜默與SYN／IDS維持有條件判讀。工具命令為供稿的語法／方向教學，沒有執行網路掃描或修改設定。
