## 圖7的精確數值附件

PNG 重繪為教學視覺；數值依 [cosine-values.csv](figures/cosine-values.csv)
及 [標準繪圖 SVG](figures/cosine-exact.svg)核對。這份額外曲線由
[redraw_cosine.py](redraw_cosine.py)直接計算，避免把生成式繪圖的像素當作數值資料。
英文軸名避免依賴讀者環境的中文字型；本頁與正文提供繁體中文軸義。

執行 `uv run --script redraw_cosine.py` 可重建 SVG、PNG 與CSV；腳本的
PEP 723 metadata 固定 Matplotlib 版本。工具環境由 uv 暫存，沒有新增 repo
虛擬環境、修改系統 Python 或安裝全域套件。腳本檢查起終點、中點及單調性。

目視檢查只證明本次圖示的可讀性及上述關係，沒有證明真實資料的 loss、速度、
召回率或學習者理解。來源圖5的互動感在靜態圖中明確改為算例。
