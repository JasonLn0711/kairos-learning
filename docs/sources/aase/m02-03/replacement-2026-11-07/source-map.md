## 查核與採用界線

2026-11-07 讀取 Hugging Face KV Cache、vLLM prefix caching、Anthropic context engineering、Lewis et al. RAG 論文與 OWASP Agent Security／Prompt Injection 說明，核對機制與權限邊界。來源連結由正式 JSON 的 sourceIds 提供。範例的需求文件 v3、測試與兩天工作流程皆為合成教學情境，並非本次執行真實 Agent 的結果。

原稿的 KV 描述補上「一般因果自回歸」與新位置仍計算注意力，以避免把快取誤解為完全不計算。Compaction 保留摘要可能遺漏；Memory 保留保存、取回、有效性三個不同判斷。這些補充與原稿分開保存在本對照表，原始供稿不變。
