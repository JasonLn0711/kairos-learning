## 三張圖的設計與差異

1. 圖 1 以五步垂直流程及四個向下箭頭，保留末步淡綠底。箭頭表示需求發現順序，沒有成效或定案保證。
2. 圖 2 保留四個有分隔線的證據層與四種裝飾圖示；HTML 文字可選取、搜尋。沒有箭頭，不暗示供述必然推出解法。單一 body 的雙段文字對應主張與限制。
3. 圖 3 保留桌面兩欄草稿／正式交接及未確認註記，手機依容器改上下；兩欄是條件比較，沒有箭頭、權限或自動交接含義。

下載圖由 `scripts/aase_m0302_svg.py` 從相同 JSON 生成六個受限 SVG（小於 100000 bytes），下載版維持固定幾何。HTML 保留圖 2 的裝飾圖示，SVG 以文字及分隔節點表達同樣分類，省略裝飾圖示；圖 3 以文字直接說明階段，未複製原參考圖的裝飾小圖。公開網站不直接嵌入來源 PNG。
