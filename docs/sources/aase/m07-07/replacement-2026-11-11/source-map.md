## 實質修正與證據

1. 開頭 m04→m07 的導航對話留在原稿，正式路徑維持 M07-07。移除 favicon／來源卡文字等擷取雜訊，正式來源由 lesson 與 section sourceIds 承接。
2. 原 Python 的換行遺失：恢復可執行縮排、保留相同函式與測試語意；可執行檔及實測見 snapshot_example.py、example-validation.md。雙語 code 完全一致。
3. AppTest 補上修改 widget 後明確 run() 的執行條件，依 Streamlit 官方 API 文件；這屬供稿的技術補充，不將 API 模擬誤稱瀏覽器驗收。
4. 雙語情境 C 補充斷言也應核對規格。斷言失敗證明不一致；根因仍需調查。
5. 原「提交答案並取得解析」及對話式「我再根據你的答案」改成既有原生參考解析；沒有新增作答儲存、評分或進度。
6. 圖 2 的匯出僅產生本機合成假資料，明示不實作真實銀行檢核。三字串快照與完整性不證明業務有效性；非空值更改也不可沿用舊結果。
7. 短段合併以符合兩語段落與模型結構，保留原論證、例子與步驟；英文同等深度翻譯。首次術語、命令、三表、五產業案例及各項限制逐節對照。
