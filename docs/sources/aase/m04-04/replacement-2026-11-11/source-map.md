### 五圖設計採用與差異

1. 需求至交付：保留五階段、問題及四條箭頭，改為在所有寬度可自然延展的直向流程。
2. 四狀態草圖：桌面並排2×2、窄版上下排列；原欄位、必填星號、合成姓名電話、狀態、動作與註記完整保留。示意動作為文字，無假按鈕。
3. 狀態轉換：以十一條具名轉換呈現原圖的八個節點、兩個判斷及所有出口。每條連線獨立列出起點、條件與終點，寬版橫向、窄版直向；這是明列關係的重排，未複製原圖跨越多列的長線。列的上下順序不表示必經流程，補填、重試、修改與未修改匯出均清楚標示。
4. Balsamiq比較：保留上方兩條重複路徑與下方共用上傳中狀態後分支；用中文／英文可搜尋文字與箭頭重製，失敗加虛線提示，保留來源歸屬。
5. 走讀任務：保留兩張獨立任務卡的完整問題，不提前揭露答案。任務文字與可取得的參考解析分開。

十個獨立 SVG 與頁面同源；下載採直向固定版面以保留文字可讀性，四狀態下載版不採2×2。SVG 無腳本、外部圖片、任意標記或事件，固定元素與屬性白名單，均小於100000 bytes。瀏覽器頁面以可搜尋 HTML 與裝飾連線呈現，不靠整張 SVG 縮小適配手機。
