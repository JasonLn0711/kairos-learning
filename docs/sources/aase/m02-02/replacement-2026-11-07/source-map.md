## 五圖設計與差異

1. **資料選取**：左側六份裝飾文件、灰米色保存區；虛線「選取」箭頭指向陶土色有限工作區；工作區四格可讀 HTML。窄版上下排列，箭頭轉向下，仍只有選取關係，不暗示全部傳入。
2. **組成列表**：五列平行組成與細分隔線；以補充用途文字取代原圖右側裝飾小圖示，保留所有標籤與服務差異。
3. **預算**：沿原圖五色分段條、圖例、數字及滑桿；超出時條寬在預算邊界截止，另以明確文字報超出量，不把視覺截斷當成服務截斷行為。下載為預設值，不冒充當前互動狀態。
4. **交接**：七欄順序與原文字意保留，標題、複製按鈕、合成路徑／測試說明直接可見；複製失敗及無 JS 都有手動方式。
5. **工作流程**：四步垂直、第三步高亮、各步副標與箭頭，重排時不改變資料流。

共用字型及卡片高度由網站與內容決定。SVG 固定桌面幾何、HTML 依容器重排；十個 SVG 從同一正式 JSON 產生，原 PNG 留在來源封存。
