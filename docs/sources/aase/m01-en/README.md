## 核對原理與教學界線

- M01-02：[NIST AI RMF 1.0 Core](https://airc.nist.gov/airmf-resources/airmf/5-sec-core/) 的 GOVERN 2.1 與 3.2 支持角色、溝通與人機責任的明確化。教學責任表與 Agent 任務契約是本系列的合成應用，不是框架認證。執行摘要、工具紀錄、權限限制及實際驗收分開；紙上練習不當成指定 Agent 已實測。
- M01-03：[OWASP Authorization Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Authorization_Cheat_Sheet.html) 支持最小權限、預設拒絕、逐請求與實際存取位置的授權檢查。本機 Streamlit 參考程式仍無多人授權；A／B／複核者案例及兩條驗收是待實作的設計，不是已通過的權限測試。
- M01-04：[GOV.UK 深度訪談指南](https://www.gov.uk/service-manual/user-research/using-in-depth-interviews) 支持開放中立問題、具體故事、追問及先向同事試問。回答、解釋、假設與驗證保留不同證據狀態；三位自願回覆者的題目不推論全體，也不編造效率改善或真人調查。

來源依原先版本核對；NIST 網頁提示框架修訂中，本課明確使用 1.0 及其既有 GOVERN 編號。新英譯逐節對照主張、條件、合成角色、數字、規則與原答案；結構驗證另核對章節順序、段落數、表格維度、圖解種類／節點及練習步數。這是本次代理的翻譯與技術核對，獨立真人審稿及試教仍待取得。
