## 格式、編輯及翻譯決定

- 原始檔逐字保留。normalize-source.py --check 驗證中文原稿經明列正規化後等同成稿；產生器 --check 再核對成稿等同正式 JSON。此鏈加上逐段頁面驗證，分別檢查來源保存與正文採用。
- 移除 favicon、NN/G+1 等來源卡雜訊、追蹤參數、複製／提交 UI 殘字；將逸出句點、反斜線換行與要求條列還原。AI 指令保留為 code，兩語共用原始中文指令以符合既有 code 相同契約；英文緊接完整英文解釋，涵蓋相同條件與限制。
- 四段圖示文字換成 figures.json 中完整節點，正文以 @figure 對應；概念交集補四個短解說以助閱讀，圖說明示非嚴格集合分類。第二節增加一行表格閱讀導引。
- 原供稿的「我會依照你的答案逐題解析」及「提交答案並請你批改」改為靜態教材的自行作答與原生參考解析，不建立沒有後端的提交、批改或進度功能。
- 五元素改為 h3 小節；原三個 HCI 與三個收件分析小節保持 h3。分出 task-analysis section 以保留舊錨點。Q04–Q06 沿原問題概念重用穩定錨點，Q07 為新實作題。
- 本次擴充心智模型、跨行業、易用性與完整需求，版號由 1.1.1 升 minor 至 1.2.0；原發布日保持，修訂日為 2026-11-11。來源日期、內容版本與發布回執分別記錄。
