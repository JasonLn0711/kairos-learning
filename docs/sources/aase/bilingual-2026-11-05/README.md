## 原理與翻譯核對

本次重讀 [Streamlit AppTest 官方文件](https://docs.streamlit.io/develop/api-reference/app-testing/st.testing.v1.apptest)及 [C4 diagrams](https://c4model.com/diagrams)。AppTest 用來模擬與檢查顯示結果；使用者理解與多人資料隔離仍需不同證據。C4 以不同層次描述結構，Context／Container 不等於權限控制實作。英譯保留這些條件、三欄完整的教學定義與合成輸入 SYN-001、DEMO-A、合成申請表；中文介面的實際輸入值保留原文字，旁附英文解釋。

模型驗證只證明結構、程式碼與識別資訊的一致；主張、語意、數字及例子另由本次代理逐段對照，不聲稱獨立真人審校。六節順序／段落數、圖解種類與節點關係、程式碼、來源 ID 及答案鍵不因語言變更；未知語言、目錄覆寫欄位、無閘門或缺少解析皆拒絕。Q&A 可保留尚未翻譯的實際中文問題；英文頁只顯示已有英譯的問題，不回退顯示中文或編造譯文。
