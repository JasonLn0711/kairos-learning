## 查核與修正

2026-11-11讀取[C4官方Context文件](https://c4model.com/diagrams/system-context)及[四層總覽](https://c4model.com/diagrams)：單一主系統、使用者及直接相連軟體系統，面向非技術讀者；依溝通價值選圖，不要求四層都畫。官網與例圖授權為[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。

原稿的favicon來源卡、聊天網址更正、圖片代理URL及utm追蹤參數從正文移除，原始來源仍完整保留。原稿銀行說明較籠統，本次按附件保留明確AWS SES名稱與郵件服務到顧客的第四條關係；沒有將虛構案例當成真實銀行部署。

模型原先要求每條Context邊都連主系統，會丟失SES → Customer。本次改為每個外部節點都必須與主系統直接相連，在此條件下允許圖中外部節點之間的補充關係。未知端點、自連、重複、孤立、無主系統直接連線、超量或任意markup欄位仍拒絕。Container與CEH契約維持。

M06-02的architecture.md為自然語言文件範本，本次允許以`# System Context — `起首的該課範本翻譯；其他課程與可執行程式碼仍逐字比對。兩語範本七節、兩向關係、三項排除及兩項備註由編輯逐項核對。
