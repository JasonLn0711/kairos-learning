問題 1：nmap -p 445 192.168.56.20 是本例的連接埠掃描；它取得 TCP 445 的狀態。smbclient -L 192.168.56.20 -U student 向 SMB 服務查詢共用資源名稱，屬於列舉。分類依操作目的與取得的證據，同一工具也可能執行其他類型的工作。

問題 2：目前不能宣稱 student 具備 Research 或 Admin 的讀取權限。回傳名稱只證明本次條件下可查詢到這些名稱；尚未連入共用、讀取指定檔案或測試寫入，因此這些操作的結果皆為未測試。microsoft-ds 這個基本掃描標籤也不能單獨取代 SMB 協定辨識。

問題 3：可寫為「在核准的實驗室測試範圍內，指定來源對 192.168.56.20 的 TCP 445 探測得到 open；以測試帳號 student 查詢 SMB，共用清單回傳 Public、Research、Admin。未測試連入各共用、指定檔案讀取或任何寫入，故無法據此判定內容存取權限或漏洞。」正式報告還應保留時間、來源、工具版本、指令及原始輸出，並以組織預期政策評估可見性；這些範例不是實際設備測試結果，也不是讀者已完成練習的證據。
