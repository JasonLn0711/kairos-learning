# M02-04 參考解答

## answer-1｜CDN 位址不是原始主機證明

不能。A 紀錄只顯示這次解析取得的位址；CDN 可能代理多個網站。沒有足夠證據證實它專屬咖啡店，更不能因此把整個 CDN 納入授權範圍。

## answer-2｜角色不同，不能互換

不能。註冊商是提供網域註冊服務的角色，不必然是網站營運者。持有人資料未公開時，應記錄公開資料不足，不猜測姓名或所有權。

## answer-3｜逾時不是不存在

不能。逾時表示沒有及時收到回應，可能與網路或服務狀態有關；NXDOMAIN 才是回覆所述的名稱不存在狀態。即使收到 NXDOMAIN，也須留下來源、時間及查詢條件。

## answer-4｜讓另一個人能照條件重查

至少保留授權範圍、查詢日期與時區、來源或解析器、網路視角、完整名稱、紀錄類型、回應狀態及原始值。若有 TTL 也一併記錄，並將「觀察」與「尚未證實的歸屬」分開。
