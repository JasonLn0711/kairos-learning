# M01-04 小檢核參考解答（網站預設收合；不當成使用者作答）

攻擊面包括公司接收外部信件的介面，以及與收信、登入有關的人員與流程。不是說信箱「有漏洞」，而是這些地方能讓外部訊息接觸到公司的人與系統，需要適當防護。

可能的攻擊向量是釣魚：假冒 IT 通知，引導員工到假網站交出帳密，再嘗試冒用帳號。不過，這裡只有看到釣魚信寄達，還不能說後面的步驟已經發生。

所以，現在不能判定帳號已被入侵。需要再查明是否點擊、是否輸入帳密、身分驗證與登入是否成功，以及是否有不當存取等證據。即使員工曾輸入密碼，也不代表攻擊者一定已成功登入，因為仍可能有其他驗證與存取限制。

可以針對這條可能路徑，檢視郵件防護、獨立管道核對通知、抗釣魚的驗證方式及登入紀錄。但看完這份參考解答，仍不等於本人已回答或理解通過。
