# CEH M02-08｜參考解答

## answer-access-control｜小檢核一

答案：B。把身分驗證及逐次授權放在伺服器端，讓核准測試群組使用名單與下載檔。noindex處理搜尋索引，存取規則處理誰能讀取；驗收同時測未登入、一般員工與核准測試人員。

## answer-hash｜小檢核二

答案：A。SHA-256比對用於核對檔案位元組與原先摘要的一致性。來源、作者、時間與取得脈絡由其他紀錄支撐；實務保留原始檔、演算法、完整摘要及取得紀錄。

## answer-retest｜小檢核三

參考答案：以未登入狀態確認名單及直接下載網址受到限制；再用核准測試帳號確認正常功能。也可加入已登入但未授權的一般員工測試。保存測試角色、日期時區、網址、版本、實際回應與最小必要截圖。依原本驗收條件逐項核對後，才記已驗收。

## answer-triage｜小檢核四

參考答案：目前已知是第三方在某時間提出舊測試站公開資料的聲稱，先保存其來源與上下文。待核是站點歸屬、目前暴露情形、資料分類及既有處置。下一步向資產負責人確認，再依核定方法查核。先確認目標範圍、允許的連線或資料取得方式、時段、負責人與保存規則；初步狀態記待查核。
