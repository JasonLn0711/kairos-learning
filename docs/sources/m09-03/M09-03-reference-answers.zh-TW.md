# CEH M09-03｜小檢核參考解答

這是教材的參考解答，不是學習者已作答的紀錄，也不代表理解已確認。網站請預設收合；不要把它填入實際 Q&A 或作答欄位。

## 1. 這三個概念能同時成立嗎？

可以。若已確認為欺騙性攻擊，SMS 簡訊對應 **Smishing（簡訊釣魚）**，電話中的誘導對應 **Vishing（語音釣魚）**，自稱資訊服務台則是 **Impersonation（身分冒充）**。

前兩個主要在描述管道，第三個在描述假扮的身分，因此不是互斥分類。知道專案名稱，只能顯示對方掌握該資訊，不能單靠這點證明他是真正的資訊人員。若有證據顯示特別針對該承辦人設計內容，還可從「目標」角度描述為定向釣魚；但題目本身不需要靠猜測補出蒐集過程。

## 2. 怎麼查證才不留在對方安排的圈子？

先停止提供資料、核准登入或安裝軟體，結束可疑通話。不要照對方指定的簡訊號碼回撥，也不要把來電顯示當成可信通訊錄。

應從自己原先使用的公司服務台、既有通訊錄或已核實的官方入口，確認有沒有這項要求、工單與承辦人，以及操作範圍和必要核准。來源獨立，比「改用電話或另一個 App」更重要。確認身分後，仍需確認這項操作有授權。

## 3. 現在能認定帳號遭入侵、教材外洩嗎？

**還不能，但應立即採取風險相稱的保護措施。**

目前已有的是收到訊息、接到電話，以及承辦人表示自己提供過登入驗證碼。這是可能的驗證資訊暴露，應立即透過正式管道通報；不需要等到損失證實才處理。

仍待查的是：驗證碼對應什麼操作、是否仍有效、是否完成登入或其他驗證、操作人是否獲授權、進一步做過哪些動作，以及是否有資料遭未授權存取或外傳。需要交叉核對時間、驗證及登入紀錄、帳號和權限變更、裝置、工單與資料活動。

負責窗口可依組織程序，評估保護帳號、撤銷可疑工作階段或處理裝置等措施。不要為了測試再次提供碼或重開可疑內容，也不要自行清除所有證據。

一句話總結：**已知風險要及時處置；成功入侵與資料外洩要各自取得證據。**
