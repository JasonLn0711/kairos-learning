# M03-07 參考答案

## answer-scope｜兩個埠代表整台主機嗎？

不能。證據只涵蓋指定來源、時間、TCP方法與8000、8001兩個埠。其他TCP埠、UDP及其他觀察位置都沒有被這次資料涵蓋。適合的紀錄是「本次指定兩個TCP埠未觀察到open」，另列未測範圍；不要改寫成整台主機沒有服務。

## answer-discovery｜-sn、-Pn 各做什麼？

-sn 做主機探索但不做連接埠掃描；-Pn 跳過一般探索判定，讓指定目標進入後續掃描。兩個選項本身都不是存活證據，還要看實際回應與判定依據。-Pn 不會把關機設備變成存活，也不會自動穿越防火牆；本地網路仍可能涉及ARP位址解析。

## answer-features｜加入 -A 前要確認什麼？

先核對核准目的是否涵蓋版本、系統、預設腳本及路徑追蹤等附加功能，以及目標、負載、時段與停止條件。-A擴充功能集合，不只是同一個兩埠連線測試的精準度開關，也不是時間範本。只需要確認入口可連線時，保留最小必要方法即可。

## answer-comparison｜open 與 filtered 怎麼比較？

兩份原始結果都保留，分別記下來源位置、時間、目標、協定、埠、方法、版本與警告；比較防火牆及服務紀錄，找出路徑或條件差異。open支持該次方法看見服務接受連線；filtered表示該次無法確定是否開啟。未核對前，不把差異直接寫成服務關閉或成功入侵。
