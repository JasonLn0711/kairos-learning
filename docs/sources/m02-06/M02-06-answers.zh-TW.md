# M02-06 參考解答

## answer-local-prefix｜本機網段練習

192.0.2.0/24 包含256個位址，範圍是192.0.2.0～192.0.2.255；192.0.2.25在範圍內。改成192.0.2.128/25後，範圍為192.0.2.128～192.0.2.255，共128個位址；.25落在這段範圍之外，因此成員檢查為False。這是整段位址數的計算。

## answer-address-count｜小檢核一：前綴大小

答案C：256。IPv4總共32位元，/24保留24位元共同前綴，剩下8位元，共2的8次方，也就是256種位址組合。24是前綴長度；128對應/25的位址數；一個IPv4位址可用/32表示。

## answer-asn-role｜小檢核二：ASN的角色

答案B：路由政策的自主系統。ASN是AS的識別號碼；使用者身分由帳號等證據建立，網頁由URL描述，TCP連接埠則標示傳輸服務入口。將這些欄位分開，就能建立清楚的角色關係。

## answer-missing-reply｜小檢核三：星號的觀察

可以寫：「本次跳數2的三個探測，在等待時間內均未收到預期回覆；跳數4收到目的端回覆。」可查核回覆過濾或速率限制，並對照實驗設備設定及日誌。觀察與原因分欄保存，下一步就很清楚。

## answer-service-correlation｜小檢核四：確認服務關係

可選：①含查詢時間與解析器的DNS結果；②含資料時間的RDAP登記及路由前綴/ASN紀錄；③自家雲端或CDN控制台中的網域、邊緣代理、後端與資產負責人設定。三者分別串起名稱、網路資源與實際服務管理；報告保留原始來源及查核時間。

## answer-integrated-prefix | 整合案例：範圍

/24 有 2^(32 − 24) = 256 個位址，從 192.0.2.0 到 192.0.2.255，包含 192.0.2.25。這是總位址數；傳統 /24 區域網路常用主機數為 254。

## answer-integrated-operator | 整合案例：營運者

AS64496 識別自治系統，路由資料支持該前綴的起源 AS 觀察。網站可能由 CDN 客戶營運，仍需資產清單、服務合約或控制台設定確認經營者。

## answer-integrated-origin | 整合案例：Origin 證據

CDN 的 DNS 回覆通常只揭示入口。由管理者的 DNS／代理控制台、Origin 設定、資產清單與服務紀錄交叉核對後端，不以邊緣 IP 推定原始 IP。

## answer-integrated-smb | 整合案例：SMB 保護

一般 HTTP 反向代理不自動涵蓋 SMB。分別核對 SMB 的路由、監聽介面、防火牆、VPN／私有網路與身分政策；不能只依網站代理狀態推定安全。
