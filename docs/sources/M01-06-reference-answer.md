# CEH M01-06｜小檢核參考答案

這次讀取被阻擋的直接證據，是資料服務的權限檢查拒絕了該次請求，並有對應帳號、目標、時間與結果的紀錄。不是因為「有 MFA」或「有告警」就能推定讀取被擋住。

MFA 是登入驗證的措施；題目已說一個登入工作階段遭濫用，所以還要靠後面的資料權限與監控。告警表示有需要查核的情況，不能直接證明所有路徑都安全，也不能單獨證明有資料外洩。這個案例只能確認已查核的那次請求遭拒，其他請求與紀錄範圍仍須調查。

備份工作顯示成功，只能支持該工作回報完成，不能保證資料完整、版本正確、能在需要的時間內還原。因此要定期測試還原，並保護備份不會和正式資料一起被刪除或加密。

白話總結：看見一扇門擋住了，不等於每扇門都查過；看見備份完成，也不等於真的救得回來。
