## CEH M01-05｜小檢核參考解答（網站預設收合）

比較準確的說法是：「已觀察到針對性的惡意附件郵件投遞嘗試，行為可對照 Spearphishing Attachment（T1566.001）；這封郵件已被閘道隔離，目前沒有足夠證據確認附件在終端執行、攻擊者取得存取權，或資料遭到竊取。」

關鍵在於：**T1566.001 是行為分類，不是入侵成功的證明。**在 Cyber Kill Chain 的觀點，可以討論投遞環節被攔截；不能因此往後推定利用、安裝、C2 或資料外傳全部發生。

「沒有找到執行證據」也不等於已證明整個環境沒有其他入侵。仍要確認日誌是否完整、是否存在其他郵件副本或攻擊路徑，並把結論限定在已查核的範圍。

展開本解答只供自行核對；沒有收到你的實際回答前，不把本課標成理解通過。
