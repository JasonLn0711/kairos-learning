## 校正、補充與保留

- 第 1 份原稱十題，僅提供第 1 題；完整保留，未捏造其餘九題或首次答對數。前版三卡與三題以補充區保留，舊錨點未移除。
- 原稿來源卡／favicon／三張外部宣傳照片不作教學正文；原始檔未改。回憶卡答案與逐項解析依正文補充，頁面明示其來源。
- 第 2 份的空白圖題（七個問題、SSD 流程）沒有未提供節點；依已提供段落承接，新增程序解說明列為編輯補充。
- 第 3 份原 Mermaid 的節點／判斷與成功失敗分支改為 HTML 流程表及解題清單；保留 DH 全部數字、DSA 方程式、參數與反元素解釋。
- TLS 引用統一現行 RFC 9846；保留前版 RFC 8446 的歷史定位。GB／GiB 明列計算，Purge 的 impossible 依標準改為 infeasible；其餘題幹歧義與威脅模型限制保留。
- 更細技術查核、版本與來源見 technical-review.md；實測與發布狀態見 docs/releases/2026-11-10-ceh-notes-reconstruction.md。
