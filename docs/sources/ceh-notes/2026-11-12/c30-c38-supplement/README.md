# C30–C38 完整供稿與採納對照

本目錄保存 2026-11-12 供稿全文及四張原始 PNG。原始 bytes 不隨編輯修正改寫；`sha256-manifest.json` 記錄五份附件的大小與 SHA-256。`before-note.json` 和獨立雜湊保存追加前的筆記，供前三部分逐物件比對。

## 原始來源與採納

- `pasted-text-1.txt`、`image-1.png` 至 `image-4.png`：原始供稿與圖稿。
- `source-units.json`：420 個原始來源單位及起訖行。
- `translations.en.json`：逐來源單位的完整英文譯文；圖文字由雙語模型採入，不以摘要取代全文。
- `diagrams.json`：四張圖的雙語模型，分別說明 SOC 與治理、告警分流、事件協調及 RPO／RTO 時間線。時間線明示教學假設與目標，不宣稱已有真實復原結果。
- `editorial-corrections.json`：版本、法規時點、指標分母與未附原題界線的實質修正；`editorial-supplements.json` 保留告警噪音量測的營運意涵。
- `adopted.json`：完整雙語第 4 部分，共 16 節、42 個小節標題、18 張表格、四張圖及六道未附答案的原始開放問題。每語 318 個正文區塊；其中一段為明列的 FPR 編輯補充。
- `adoption-map.json`、`line-map.json`、`chapter-map.json`：逐單位、逐行、逐章與小節的去向；僅來源卡、favicon 與其來源介面標籤排除於正文，原文仍完整保留。

## 呈現與查核界線

沿用既有語意 HTML 與內容模型。來源的空白比較欄標頭補為「比較項目」／“Comparison”；公式改成可讀文字。既有 inline renderer 支援受限的 HTTPS Markdown 連結，不渲染任意 HTML 或 Markdown 反引號；採納文字已移除不支援的格式殘留。連結移除 `utm_` 追蹤參數，原始供稿保持不變。

供稿所述原題編號及課程歸屬予以保留並明確歸因；未提供的 Day01-A 原題全文不視為已獨立核查。NICE 框架結構與另行維護的元件版本分開說明，ATT&CK 採查核時的戰術分類；FPR 與告警中的誤報比例分別定義分母。銀行公會日期標示為網站公告日期，並與文件版本及施行日區分。

金融法規另分開說明第 55 條施行日期及第 54 條對特定機構、制度事項的 2027-12-31 調整期限。美國營業秘密揭露免責限於 §1833(b) 的指定對象、目的及責任範圍，並保留 (b)(5) 對非法取得的限制。

重建命令：`python3 scripts/ceh_note_c30_c38.py --write`；重現與保全檢查：`python3 scripts/ceh_note_c30_c38.py --check`。正式筆記由全域重建器呼叫 `adopt_c30_c38(note)`，保留前三部分，追加第 4 部分並採內容版本 1.1.0／修訂 2。
