# M02-03 參考解答

## answer-1｜搜尋結果、規則與安全證據

① 不能。摘要只能證明搜尋服務在查詢當下顯示該線索；要核對目前公開狀態，需在授權範圍內檢查原始資源，並記錄時間。不要因為舊摘要就宣稱現況。

② 不能。robots.txt 是給配合規則的爬蟲的指示，不是權限檢查。noindex 也只是索引規則，不能代替私人內容的存取控制。

③ 不能。標頭可能來自代理層，也可能是舊字串或被簡化的標示。版本、設定、適用條件與實際弱點都需要另外授權的驗證。

④ 由站方在核准範圍內，以未登入、一般帳號及有權限帳號比較存取結果，檢查伺服器端是否依資源與身分落實授權。保留測試範圍、帳號角色、時間及結果；搜尋不到或單獨看到某個狀態碼，都不足以取代完整權限驗證。

## answer-noindex｜私人 PDF 的存取設計

知道完整網址的人仍可下載這份公開 PDF。noindex 管理搜尋索引；檔案的交付由網站存取設定決定。改為會員專用時，伺服器先驗證登入身分，再確認該會員對這份 PDF 的讀取權限，通過後才交付檔案。以未登入、已登入但未獲授權、已獲授權三種角色驗證，並檢查實際內容及回應。
