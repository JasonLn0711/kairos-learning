# M02-07 參考解答

## answer-source-independence｜小檢核一：共同來源

答案 B：一個原始來源、三個刊載位置。三篇都引用同一份 2023 年介紹，可保留刊載位置以利回查；身分與當期職稱則另找獨立維護的現行官方紀錄。A 把轉載算成獨立確認；C 混淆資料年份；D 用篇數取代來源與時間查核。

## answer-deep-web｜小檢核二：私人信箱

答案 B：深層網路內容。登入後的私人信箱通常在一般搜尋索引之外，內容依登入與權限規則提供。表層網路指可索引的公開內容；Tor 洋蔥服務另有特定網路與 .onion 位址；外洩是資訊暴露事件，與這項索引分類分開判斷。

## answer-exposure-claim｜小檢核三：外洩聲稱的查核

可保存發布者／來源位置、發布時間與時區、聲稱的資料年份與類型，以及通知服務的「未驗證」狀態。下一步依授權對照自家帳號或系統日誌、正式供應商事件公告等。可寫：「11/1 收到服務轉述的未驗證外洩聲稱，資料自稱來自2022年，已交由事件應變窗口核對相關紀錄。」保存最小必要資訊並遮罩個資與秘密。

## answer-defensive-action｜小檢核四：內容與流程防護

內容調整：由負責人更新照片，遮除內部專案名稱等非必要公開資訊，並以公開訪客視角確認修訂結果。流程防護：公告已核實的正式系統入口；遇到以該專案名義提出的付款、登入或帳號異動要求，透過已知聯絡管道與核准流程確認。這同時減少可被拼湊的細節，並讓要求有可追溯的驗證途徑。
