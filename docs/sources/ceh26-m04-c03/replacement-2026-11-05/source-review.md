# 技術來源校對｜2026-11-05

核對使用者供稿的協定、命令與推論界線：

- [RFC 959](https://www.rfc-editor.org/rfc/rfc959)：FTP 控制／資料連線、RETR／STOR 及回應碼。
- [RFC 3659](https://www.rfc-editor.org/rfc/rfc3659)：MLST／MLSD 的中繼資料與目錄查詢。
- [RFC 4217](https://www.rfc-editor.org/rfc/rfc4217)：FTPS 的控制與資料保護分開核對，PROT P 是要求，不取代實際保護證據。
- [OpenSSH sftp](https://man.openbsd.org/sftp)：透過加密 SSH 傳輸的獨立檔案傳輸工具／協定。
- [RFC 6409](https://www.rfc-editor.org/rfc/rfc6409)與[RFC 8314](https://www.rfc-editor.org/rfc/rfc8314)：郵件提交、587／465 與伺服器間 25 的角色。
- [RFC 5321](https://www.rfc-editor.org/rfc/rfc5321)：EHLO 多行回覆、VRFY／EXPN 與個別 SMTP 步驟回應；252 不確認使用者，不證明帳號不存在或已寄達。
- [RFC 4954](https://www.rfc-editor.org/rfc/rfc4954)與[RFC 3207](https://www.rfc-editor.org/rfc/rfc3207)：AUTH 功能宣告與成功驗證、STARTTLS 後重新 EHLO，以及逐傳輸區段保護。

本稿保留供稿的簡化合成紀錄；例如 230／252 後文字不是聲稱所有伺服器逐字一致。回覆須配對命令、身分、政策與操作結果。未連線 FTP／SMTP 目標、未測試匿名權限或轉送；網站驗收不代表 NAS、郵件服務、學習者理解或官方考試準備度已通過。
