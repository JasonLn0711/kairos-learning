# M04-03 FTP / SMTP source preservation

New stable ID CEH26-M04-C03; public slug m04-03. Initial v1.0.0, 2026-11-04 Asia/Taipei.

The full Traditional Chinese manuscript is retained byte for byte. The paired English manuscript retains every section, number, protocol condition and evidence limit. Only Markdown emphasis is removed for the existing sourceBody presentation; transcript lines are grouped into selectable code blocks without changing their text. Two separately authored parallel card diagrams supplement, rather than replace, the prose. Answers are editorial reference material; qa is empty.

The source-review.md lists thirteen primary references and scope. sha256.json records all four manuscripts. detailed-section-map.json binds both languages to the same section IDs. diagram-models.json feeds both HTML card text and sanitized SVG downloads. The exporter checks bounded text, fixed card-only structure, safe SVG and deterministic ZIP. No arbitrary HTML or external SVG is accepted.

Maintenance: run scripts/ceh26_m04_c03_content.py and scripts/ceh26_m04_c03_diagrams.py; each supports --check. Run existing content, unit, type, boundary and release gates. Keep browser observations separate from automated tests and from formal deployment.

The retired M04 manuscripts and assets remain in their existing non-output archive. C01/C02 teaching is unchanged; C04–C10 remains unpublished. No learner answer, delivery ID or personal record is included.
