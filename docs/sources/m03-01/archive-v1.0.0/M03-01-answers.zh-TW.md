# CEH M03-01｜參考解答

## answer-layer-roles｜小檢核一

答案：C。IP 協助定址與轉送；TCP、UDP 等傳輸協定中的連接埠協助作業系統把資料分派到通訊端點；實際程式依應用規則提供服務。閱讀紀錄時把位址、協定、埠與服務證據串起來。

## answer-port-protocol｜小檢核二

答案：A。TCP 與 UDP 使用各自的埠號空間；TCP/443 與 UDP/443 要分別辨識。常見情境是 TCP 上的 HTTPS 與 UDP 上的 QUIC／HTTP/3，實際用途再核對服務設定與協定回應。

## answer-handshake-login｜小檢核三

參考答案：TCP 三向交握讓雙方同步起始序號並建立傳輸連線狀態；網站登入是應用程式驗證帳號身分。若使用 HTTPS，還會依服務流程建立 TLS 安全通道。每一層分別查看它的結果。

## answer-service-evidence｜小檢核四

參考答案：保存來源及目的 IP、來源及目的埠、TCP 協定、時間與觀察位置，並記實際回應。可查主機監聽與程式設定、資產清單、反向代理設定及負責人的管理紀錄；授權測試中再核對協定回應。8443 是可形成假設的線索，具體用途由這些證據確認。
