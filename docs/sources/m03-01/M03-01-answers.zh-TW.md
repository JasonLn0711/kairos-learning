# M03-01 參考解答

## answer-layer-roles｜為什麼只有 IP 不夠？

IP 協助定位網路介面；同一個位址可以提供多個服務。還要看傳輸協定與目的 Port，才能區分要連接的通訊端點。例如 TCP/22、TCP/80 與 TCP/443 常分別用於 SSH、HTTP 與 HTTPS，但實際服務仍需設定或回應佐證。

## answer-handshake-login｜TCP 交握成功是否等於登入？

三向交握建立 TCP 傳輸狀態。HTTPS 還需 TLS；帳號登入與操作權限則由應用程式的身分驗證與授權判定。通訊管道建立本身不授予帳戶或資料存取權。

## answer-realtime-loss｜語音遺失後應該等待嗎？

依播放期限與應用需求決定。已超過播放時點的聲音可能不值得等待；系統可以用抖動緩衝、遺失補償或選擇性重傳，讓後續聲音繼續播放。UDP 本身不自動重傳，不代表上層不能提供可靠性；也不能只憑 TCP 或 UDP 名稱判定效能。
