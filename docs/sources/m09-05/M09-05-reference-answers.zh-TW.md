# CEH M09-05｜參考解答

## 1. 為什麼不能直接認定小安惡意偷資料？

紀錄首先指出的是「哪個帳號做了什麼」，不是已經證明「哪個人抱著什麼目的操作」。要確認至少兩件事：這次下載是否經過核准、符合工作需要？是否確實由小安本人操作，還是帳號或登入狀態遭冒用？另外也應確認紀錄代表成功完成下載還是僅送出要求、涉及哪些資料，以及是否傳給未核准對象。

圖2的紅色虛線只是可能越界的路徑；圖4要求先查紀錄與工作脈絡，不能把告警直接當成惡意行為的判決。

## 2. MFA能單獨防止本人濫用合法權限嗎？

不能。MFA主要幫助驗證登入者；若真正的小安通過驗證，他仍可能濫用原本可用的功能。應在圖2的「用途／分享權限邊界」加上對應控制，例如限制可匯出的資料範圍、名單外傳需由另一位有權人員核准、限定核准的收件人或通道，並保留稽核紀錄。

必要時搭配DLP辨識或阻擋敏感資料傳送。但不能保證抓到所有情況，也不能只憑DLP告警判定惡意。重點是身分驗證、授權與監督各自處理不同問題。

## 3. 證件影本外洩，可以確認什麼？

可以確認的是：依題目給定條件，證件影本已外洩，敏感身分資料面臨冒用風險。不能直接確認的是：已有帳號遭接管、已有冒名申辦成功，或已造成某筆特定損失。這些都需要另外查證。

申請資料正確，只能顯示申請者掌握這些資料，不足以證明他就是資料本人或獲得授權。圖3右側的新服務申請，應依適當的身分查核程序，查核證據以及申請者與該身分的連結；不能把「知道資料」當成「就是本人」。同時應保留必要證據、依可信管道處理疑似冒用，避免讓更多個資外流。
