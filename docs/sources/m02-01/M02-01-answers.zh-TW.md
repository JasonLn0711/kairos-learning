# M02-01｜參考答案

## 1. 同一個瀏覽器，不同資料流

讀既有摘要時，主要箭頭是「我 → 搜尋平台」；點官網後，是「我 → 目標網站或其代管服務」。工具一樣，接收請求的系統不同。本堂採直接互動的定義，因此後者不是零互動；正常瀏覽仍不等同漏洞掃描。

## 2. 第三方 DNS 不保證沒有間接互動

不能保證。解析器可能從有效快取回覆，也可能繼續向其他伺服器詢問。還需知道快取、轉送與實際解析路徑；只知道工具或解析器名字不夠。權威服務看到的來源也可能是解析器，不是原始查詢者。

## 3. 三種證據，三種有限結論

舊職缺只能支持「當時公開文件提及某技能」；服務回應支持「特定時間、位置與請求條件下有回應」；負責人的現行清單可支持其涵蓋範圍內的資產歸屬與狀態。三者都不能單獨證明可被入侵。技術版本、設定、可達性與實際弱點仍須在授權內另行核實。

## 4. 發現新線索，不等於範圍自動擴大

先記錄來源、時間、可能關聯與不確定性，列為待確認；請負責人核對，必要時先更新授權。原本允許的副本分析可繼續，但不要直接探測新主機。可疑範圍與異常情況依既定停止、通報規則處理。
