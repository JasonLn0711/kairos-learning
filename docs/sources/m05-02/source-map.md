## 圖意與差異

圖1維持10×10格與30／70顏色分配；圖2寬版保留A上層、B/C平行下層與依賴分支，手機上下重排時每一子項明示A→，不畫B→C；圖3維持五步垂直順序與四箭頭；圖4維持80%進度條、8/10及一致項目假設。HTML文字可搜尋選取，SVG獨立下載；標題、圖說、body共用模型。圖示省略原globe／database／card裝飾符號，增加圖號與文字圖說，低彩度樣式依站點。SVG為固定幾何，網頁為容器重排。

產生器沿用既有 wrap 與 sanitized_svg，固定元素及路徑、不接受任意標記；concepts.ts限制課程、種類及節點數。八檔各小於100000 bytes，實際bytes與下載結果見瀏覽器回執。原PNG未當正式文章圖片。
