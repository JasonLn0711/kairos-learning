# M03-04｜小檢核參考答案

## answer-observation-location｜1. 同一入口、不同位置

兩份結果分別描述不同來源的存取條件：管理網段的 SYN 探測收到服務接受連線的回應，其他網段的探測呈現過濾情況。若政策原本只允許管理網段，這是可繼續驗收的線索。補上兩類證據：一、服務接聽與綁定設定；二、防火牆允許／拒絕規則與同時段日誌。一起核對來源、時間及方法，就能確認結果是否符合設計。

## answer-response-states｜2. RST 與 UDP 沉默

TCP SYN 探測收到 RST，通常分類為 **closed**。UDP 探測重試後仍沒有回應，通常分類為 **open|filtered**：服務可能只回覆符合格式的資料，路徑上的過濾也可能造成沉默。保留原始回應與測試條件，再依服務與防火牆紀錄查核。

## answer-ack-followup｜3. unfiltered 的下一步

ACK 掃描的 unfiltered 表示該探測可得到回應，重點是過濾行為。接著在核准範圍內使用 TCP SYN 或 Connect 等適合的方法，觀察服務是否接受連線，並對照設備端的接聽設定；若要確認應用程式用途，再做核准的應用層查核。

## answer-report-fields｜4. 補齊查核紀錄

至少補四項，例如：目標 IP 與核准用途、來源網段、時間與時區、UDP 掃描方式與工具版本、等待／重試設定、探測資料格式、無回應的原始輸出與判定理由、服務接聽與 DNS 日誌、防火牆規則與日誌。保留 UDP 53 的傳輸協定和埠號，並列出下一步核准的服務格式查詢及負責人，讓其他人可以重現並接續處理。
