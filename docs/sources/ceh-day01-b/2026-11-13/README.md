## 八圖設計對照（已逐張閱讀）

1. 威脅模型 → 四個平行安全機制 → 協定、實作及金鑰生命週期；中間四機制不能畫為時序鏈。
2. 對稱／非對稱兩平行欄；前者共享秘密，後者公私鑰分工；簽章另有流程。
3. AES-256：128-bit 區塊與 256-bit 金鑰兩平行參數，所有 AES 金鑰版本區塊相同。
4. 五個 AES 決選者並排，Rijndael 明確標記獲選，年份 2000。
5. 簽署與驗證兩個流程；明示訊息、簽章、公鑰三個驗證輸入，避免把驗證解讀成私鑰加密的逆運算。
6. Root CA → Intermediate CA → Server Certificate，箭頭為簽發關係，驗證沿信任路徑處理。
7. 五階段整合案例依次：身分、金鑰、傳輸、文件驗證、儲存復原；簽章為按需求另行使用。
8. 六個時間段：10、60、10、40、40、20 分鐘，合計180；比例圖必須符合數值，原圖僅作風格參考。
