## 本機練習實測與界線

在不含敏感檔案的暫存目錄啟動 Python 3.12.3 的 `python3 -m http.server 8080 --bind 127.0.0.1`。ss 確認監聽；curl -I 得到 HTTP/1.0 200 與 `Server: SimpleHTTP/0.6 Python/3.12.3`。Nmap 7.94SVN 的一般掃描顯示 8080 open／http-proxy；加 -sV 後辨識為 http／SimpleHTTPServer 0.6 (Python 3.12.3)。服務紀錄含 HEAD 與後續探測。最後送出 Ctrl+C 對應的 SIGINT，確認本次 listener 已關閉，暫存目錄已清理。

這些結果證明本次 localhost 教學步驟可執行，不代表漏洞成立、修補完成或學習者已掌握。本機原始輸出在 `.local/m0305/examples/`；包含其他本機 listener 的原始 ss 清單不發布。沒有變更 Nginx、更新套件、操作 Cloudflare 或掃描外部目標。實體手機與完整螢幕閱讀器仍待人工驗收。
