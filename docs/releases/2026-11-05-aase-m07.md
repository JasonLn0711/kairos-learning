Git 審查分清工作區、暫存區及未追蹤檔案。復原保留其他工作，不提供整個專案強制重設捷徑。Session State 與快照只處理本課本機文字欄位，不提升為正式簽章、多人一致性、安全刪除或正式受理證明。
