本 repo 是課綱、網站教材與工作坊資源的正本。使用者於本對話提供「CS Kairos｜AI 協作軟體工程完整系列課程規劃」，本次依供稿建立 [49 個概念資料](../../content/aase/course.json)，保留九個模組、概念名稱、分鐘數、共同案例與交付方向。另為每個概念新增可觀察的學習目標、練習及驗收條件。該 JSON 是結構化擷取，並非供稿全文存檔。

分享對話連結未能取得正文。供稿提及的《10 小時整合課程 V0.3》、規劃 ZIP、M04-05 詳細範例、SVG 學習地圖與其餘附件尚未收到。供稿中的「已建立交付包」是來源敘述，不是本 repo 已存在檔案的證據。原檔若取得，可逐項比對並保留差異，不能覆蓋成相同來源。使用者已表示 ZIP 找不到；後續編寫採已提供的規劃與可核對原始來源，不以原 ZIP 為前置條件。

## 學員與能力目標

對象為需要和 AI 一起製作工作用軟體的初學者與領域工作者。入門條件為能操作檔案、瀏覽器及依指引執行命令；教師需在課前確認 Python、編輯器與選定 Agent 可用，提供已驗證環境。學員不需已有架構師能力。

完成學習後，學員應能將工作問題改寫為有邊界的需求，設計可復原的操作流程，以規格約束 Agent，完成三次垂直切片，留下可重現的測試與交接證據。線上閱讀、問答分數、實作通過與組織正式上線分別記錄。

## 兩種學習模式

線上系列以九模組、49 個獨立概念構成長期學習路線。工作坊為 600 分鐘淨教學，包含 150 分鐘實作，不含休息。每個模組的分鐘數與實作分鐘數以 JSON 為單一來源。

供稿建議現場深講 26 個、概覽 20 個、延伸 3 個，但未提供完整逐篇分配。本次編輯分配記錄於 `workshopDepth`；三個延伸為 M02-03、M05-05、M09-04，其餘可按授課回饋調整。此分配不冒稱來自 V0.3 附件。

採同一個合成收件資料完整性檢核案例。學員先定義誰需要何種結果，再製作表單、檢核、預覽與匯出。刑事局、醫療、企業及研究室為替換案例包；尚未核實的內部流程不編為正式要求。

## 網站與出版邊界

正式系列路徑 `/courses/aase/v1/`，模組路徑 `/courses/aase/v1/m01/`，概念路徑 `/courses/aase/v1/m01/concepts/m01-01/`。教材識別碼使用 `AASE-M01-C01`，與 CEH 完全分開。系列 URL 版本 `v1` 與教材語意版本 `1.0.0` 是不同欄位。

概念待完成時只在目錄顯示「準備中」，不產生空白教材路由、搜尋項目、測驗或學習完成紀錄。先完成 M01-01、M03-01、M04-05、M05-03，核對來源、白話例子、最小實作、檢核與前後導覽後才開放。M01–M09 的 49 篇中文正文已補齊；未來撤回或尚未完成的語言仍遵守發布閘門。

每篇教材依 repo 的 WRITE、HTML、FIG、INT、A11Y 規則。圖解依教學需要選用；使用受限資料模型與既有 HTML／SVG 元件，不為湊圖數新增裝飾圖。各篇英文未完成時，不建立該篇英文教材頁或指向不存在的語言切換。沿用 CEH 既有搜尋及閱讀方式，但不把 AASE 資料插進 CEH 模組列表。

Streamlit 在本機或另行提供的教學環境執行；靜態網站只供教材及下載。教學原型不預設具有多人隔離、正式身分系統或組織部署能力。共同使用前需另外核對授權、儲存、備份、部署與治理要求。

## 整合理解評量

情境：十位同仁將共同使用本機收件檢核原型。不同承辦人應只能存取獲授權的資料；主畫面保持簡潔；資料不齊時不得輸出標記為完整的報告。

1. 需求：提出訪談問題，畫出工作流程，決定 MVP 與不做清單。
2. Agent：說明可委派工作、人類決策、工具與檔案權限限制。
3. UX：交代必要狀態、設定的放置方式與任務試用方法。
4. 規格與架構：寫三條 Given／When／Then，連結 Context、Container 與授權檢查。
5. 實作與驗證：安排三次垂直切片，搭配 pytest、AppTest、同儕任務及安全負向情境。
6. 交付：展示 Git、README 與測試證據，指出原型驗證仍未涵蓋的上線風險。

每題以「可操作、可追溯、能指出限制」評閱。參考方向與評分規準見 [工作坊教師指南](../../resources/aase/instructor-guide.md)；題目與規準完成不代表學員通過。
