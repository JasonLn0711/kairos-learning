# CEH M01-07｜小檢核參考解答

公司把「有某範圍的管理制度驗證」、「這次告警是不是誤報」與「事件是否已處理完」混成同一件事了。

驗證不能單獨證明這次下載合法；關閉告警只代表通知或追蹤狀態被改變，也不能證明問題已排除。

可以先找兩類證據：

1. 實際操作證據：帳號、時間、下載對象、存取結果與相關紀錄是否完整。確認發生了什麼，不只看告警標題。
2. 授權與工作脈絡：該帳號原本能做什麼、是否有核准的備份或工作需求，以及驗證和系統的實際範圍。

如果有未授權跡象，依程序評估與處置；如果是正常活動，也要記錄查證依據。資料不足就保留待確認，不必急著二選一說「絕對安全」或「一定被駭」。

風險管理仍要持續進行，確認控制有效、責任清楚及環境有沒有改變。

本段是教材參考答案，不是使用者作答或理解已通過的證據。
