## 逐章逐小節對照

有供稿的抽換、補充或完整修訂，沿用來源紀錄填寫；已有對照檔可在此連結，不必重複建立。列到實際教學小節與情境分支，不能僅列章名。每列的「核對結果」須根據正文閱讀與比對，不以標題數或關鍵字代填通過。

| 原文章／小節及來源位置 | 成稿位置／錨點（雙語適用時列兩語） | 保留的解釋、案例、步驟與其他內容 | 實質修正／合併理由與依據 | 核對結果／漏項 |
|---|---|---|---|---|
| | | | | 尚待核對 |

另記錄原文到成稿、成稿到建置頁、正式頁回讀各自的證據。自由改寫核對意義與教學深度；逐字採用核對全文及明列修正。相同來源檔不免除使用者更正要求後的重新驗收。
