# 全站文章寫作與響應式教學規範

採用日期：2026-11-01。適用所有觀點、CEH、AI、網路與 MATLAB 教學頁面。新增與修訂文章必須遵循；既有差距由盤點追蹤，保留原始教材與發布歷史。

## Agent 工作流程

閱讀本規範及對應內容指南 → 確認讀者與主要問題 → 查核來源 → 檢查內容模型及元件 → 撰稿與圖解 → 雙語核對 → 逐頁瀏覽器驗證 → 記錄結果。現有模型沒有需要的能力時，先記錄差距，不能插入任意 HTML 繞過驗證。

## 圖解與技術選擇

沿用 Svelte、HTML、CSS、SVG；單張圖不新增框架或外部服務。Downloads 的 index-example.html 示範 HTML 節點、SVG 圖示及雙欄轉單欄；採其重排原則，核心補充說明改為直接可見。原檔所連結的獨立 SVG 未隨檔提供，不能當作已完成交付。

最小排版範例（SVG 圖示為裝飾，完整意義由文字承接）：

```html
<figure>
  <div class="comparison">
    <section><h3>直接連線</h3><p>瀏覽器 → Apache：HTTPS</p></section>
    <section><h3>代理連線</h3><p>瀏覽器 → 代理：HTTPS</p><p>代理 → Apache：HTTP 或 HTTPS</p></section>
  </div>
  <figcaption>兩種 TLS 終結位置；實際部署需核對入口設定。</figcaption>
</figure>
<style>
.comparison { display:grid; grid-template-columns:repeat(auto-fit,minmax(min(100%,20rem),1fr)); gap:1rem }
.comparison section { min-width:0; padding:1rem; border:1px solid #64748b; border-radius:1rem; overflow-wrap:anywhere }
</style>
```

## 驗收紀錄

每頁記錄 URL、語言、規則 ID、尺寸、結果與證據。狀態使用「通過／發現差距／尚待人工檢查／不適用」。自動盤點不等同完整無障礙認證。人工檢查圖中文字、連線關係、焦點、200% 放大與閱讀順序；未執行即保留待驗。

參考：[重排](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)、[文字放大](https://www.w3.org/WAI/WCAG22/Understanding/resize-text.html)、[鍵盤](https://www.w3.org/WAI/WCAG22/Understanding/keyboard.html)。

共用[撰稿工作表](article-writing-template.md)；執行 `npm run audit:articles` 產生[逐頁盤點](article-audit.md)。此指令建立本機網站，寫入忽略的瀏覽器證據與公開摘要；不部署。

[本次成果、驗證與跨 repo 關聯](releases/2026-11-01-perspectives-standards.md)記錄實際結果及後續驗收。

M01–M02 的既有教材套用範例見[全篇改善與逐頁驗收](releases/2026-11-01-m01-m02-readability.md)：以逐篇導讀、可換行圖解文字與鍵盤捲動改善閱讀，同時保留原稿及原圖；維護時依[資料契約](content-authoring.md#m01m02-閱讀導引與可換行圖解)重跑驗收。


## 原發布、版本與修訂日期（WRITE-06）

文章摘要下方沿用一列低彩度小字，以間隔點分開資訊；手機自然換行，不另加卡片、圖示或醒目徽章。日期格式統一 `YYYY-MM-DD`，按 Asia/Taipei 的實際編輯日期記錄，使用 `<time datetime="…">`，文字至少 14 CSS px、行高至少 1.7。

標準顯示：`原發布 2026-10-23 · v1.2.1 · 版本修訂 2026-11-01`。英文對應 `First published`、`Version revised`；兩語共用同一筆日期。

- **原發布日期**：文章第一次發布的日期；後續修改保留原值，另依現有發布閘門處理上線。
- **目前版本**：所有新文章及修訂文章統一採 `vMAJOR.MINOR.PATCH`，例如 `v1.0.1`，不以 `v1`／`v2` 或內部 revision 代替。初版為 `v1.0.0`；白話改寫、閱讀改善與不改變核心結論的修正升 PATCH；增加教學範圍升 MINOR 並將 PATCH 歸零；改變核心結論、學習契約或需重做原操作流程的重大重構升 MAJOR，後兩碼歸零。資料欄位 `contentVersion` 儲存不含 v 的三段非負整數，顯示時加 v；`revision` 僅作內部遞增計數。歷史整數版號遷移須記錄基準與影響，保留 Git 歷史，不聲稱過去曾顯示語意版本。NAS 原 v1 以 1.0.0 為遷移基準，本次白話修訂顯示 v1.0.1，先前 v2 屬誤標。
- **版本修訂日期**：目前內容版本完成修訂的日期，與該版本的修訂紀錄一致。新文章初版可與原發布日相同。未有可信紀錄的舊文章先省略此欄，列入待補紀錄，不推算或用今天代填。
- **閱讀改善就是版本更新**：導讀、文字易讀性、圖解文字替代、排版、響應式及無障礙操作等會改變讀者閱讀體驗的修訂，都納入文章版本。未改變核心教學範圍時提升 patch（例如 `v1.1.0 → v1.1.1`）；新增教學範圍依既有規則提升 minor，重大重構依規則提升 major。同時更新版本修訂日期、遞增內部 revision，保留原發布日。資訊列一律不另設「閱讀更新」。
- **內容校對與觀察日期**：校對日期表示查核，觀察日期表示事件資料範圍；各自保留原意，不替代版本修訂日。

執行順序：確認原發布紀錄 → 判定修訂影響與版本級別 → 維護版號與對應日期 → 記錄修改摘要 → 核對中英資訊列與 320px／200% 文字 → 經授權發布後補上正式回執。重新建置、測試、部署及只改日期顯示元件，都不自動改寫文章日期。
